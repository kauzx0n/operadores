Operadores JS

Um mergulho profundo na sintaxe do JavaScript. Entenda como o motor do JS interpreta os dados, evite bugs clássicos de coerção e escreva códigos com a elegância de um sênior.

Matemáticos Avançados

Além do básico (+, -, *, /), o operador de **adição (+)** no JS tem um comportamento duplo: se houver uma string envolvida, ele concatena em vez de somar. Esse é um dos maiores causadores de bugs para iniciantes.

Outro herói subestimado é o **módulo (%)**. Ele não calcula porcentagem, mas sim o resto da divisão. É incrivelmente útil para descobrir se um número é par ou ímpar (n % 2 === 0) ou para criar loops infinitos em arrays.

// A pegadinha da concatenação
console.log(10 + 5); // 15 (Soma)
console.log(10 + "5"); // "105" (String!)

// Identificando números pares/ímpares
const isEven = (14 % 2) === 0; // true

// Exponenciação (ES7) mais limpa que Math.pow()
console.log(2 ** 4); // 16

A Lei do === Estrito

JavaScript tenta "ajudar" você convertendo tipos automaticamente (Coerção de Tipo). Por isso, usar apenas dois iguais (==) é um risco brutal. Ele considera que o número 0 e o valor booleano false são a mesma coisa.

Para manter seu código previsível e seguro, a regra da indústria é unânime: Sempre utilize a igualdade estrita (===) e a desigualdade estrita (!==). Elas validam primeiro o tipo do dado e depois o valor.

// O terror do operador fraco (==)
"" == 0; // true (Isso é loucura)
false == 0; // true

// A segurança do operador estrito (===)
"" === 0; // false
false === 0; // false

// Verificando diferença estrita
10 !== "10"; // true

Magia do Curto-Circuito

Os operadores && (AND) e || (OR) fazem muito mais do que retornar true ou false. Eles aplicam o conceito de Short-circuit Evaluation (Avaliação de Curto-Circuito).

Eles retornam o valor real do operando que definiu a operação. No React, usamos o && constantemente para renderização condicional: se o lado esquerdo for verdadeiro, ele "passa" e renderiza o componente do lado direito.

// && retorna o 1º valor falso ou o último valor
const user = "João" && "Logado";
console.log(user); // Retorna "Logado"

// || retorna o 1º valor verdadeiro ou o último valor
const nome = "" || "Visitante";
console.log(nome); // Retorna "Visitante"

// Exemplo clássico em React
// isLoading && <Spinner />

Ternário: If-Else Express

O Operador Condicional (Ternário) é o único no JS que exige três operandos. Ele é a ferramenta perfeita para atribuir valores variáveis com base em uma condição, evitando a verbosidade de blocos if...else gigantescos.

Aviso de Sênior: Não aninhe múltiplos ternários (um dentro do outro). Isso transforma seu código em um quebra-cabeça ilegível. Use apenas para decisões simples e diretas (A ou B).

let saldo = 1500;

// Atribuição direta baseada em condição
const statusConta = saldo > 0
  ? "Conta Positiva"
  : "Conta Negativada";

console.log(statusConta); // "Conta Positiva"

Nullish Coalescing (??)

Antigamente, usávamos o || para definir valores padrão (fallback). O problema é que o || considera 0, "" (string vazia) e false como valores nulos, o que causava bugs terríveis em sistemas de pontuação ou formulários.

O operador de coalescência nula (??) resolve isso magistralmente. Ele só aciona o valor padrão do lado direito se a variável for estritamente null ou undefined.

const temperatura = 0; // Zero graus é um valor válido!

// O || ignora o 0 achando que é falta de valor
const exibeTemp1 = temperatura || 25; // Retorna 25 (BUG!)

// O ?? respeita o 0, pois não é null nem undefined
const exibeTemp2 = temperatura ?? 25; // Retorna 0 (Correto)
ES2020

Optional Chaining (?.)

Você provavelmente já viu este erro na sua tela: "TypeError: Cannot read properties of undefined". Isso acontece quando tentamos acessar propriedades dentro de objetos que ainda não existem no retorno da API.

O Encadeamento Opcional (?.) permite que você navegue por propriedades profundas de um objeto. Se a referência não existir, ao invés de explodir sua aplicação com um erro, a expressão "desiste" e retorna suavemente undefined.

const player = {
  id: 1,
  stats: { level: 99 }
};

// Tentando acessar algo que não existe (guild)
// player.guild.name -> CRASH! O app quebra.

// Usando o ?. o código sobrevive
const guildName = player.guild?.name;
console.log(guildName); // undefined
